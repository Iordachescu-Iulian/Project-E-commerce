What the demo proves

4 categories · 16 games · 32 editions · 64 generated images, all read from MySQL at 127.0.0.1:3307. A missing cover falls back gracefully and a zero-stock edition is visibly out of stock.

Server-side by design

Prisma is imported only in src/server/* and route handlers. Passwords never leave the server as hashes; the session cookie is httpOnly, SameSite=Lax and signed with HS256.

Bonuses

B4 sales dashboard · B5 discount codes

B4 · 3 points

Daily sales, top products, average order

Admin dashboard over a selected interval: a daily sales chart, the top five products by revenue and the average order value. Computed with grouped SQL aggregates, not hard-coded numbers.

  • Data: Order.paidAt, Order.total, OrderItem.quantity.
  • Filter: from/to dates, default last 30 days.
  • Owner: Cosmin · week 11.
B5 · 3 points

Percentage or fixed discounts

A code has a type, value, optional expiry and maximum number of uses. Validation happens on the server at checkout; the used counter increments once per paid order.

  • Model: DiscountCode + Order.discountCodeId.
  • Admin: list, create, edit, deactivate.
  • Owner: Iulian · week 11.

Only B4 and B5 are claimed. Bonuses score only after A1–A12 work, so both land in week 11, after checkout and admin.
